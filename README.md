# Yaku

Alertas satelitales para el agua del norte jujeño.

*Yaku* significa "agua" en quechua. Es una plataforma web que vigila el agua del norte de Jujuy con datos satelitales y de modelos meteorológicos, y la traduce a un semáforo de riesgo por zona con avisos a tiempo: cuando sobra y amenaza con aludes, y cuando falta y seca la Puna.

## Estado

Proyecto en construcción durante el Cursor Hackathon Jujuy (22/11/2026, a bordo del Tren Solar).

## Origen del proyecto

Todo el código de este repositorio se escribe durante el hackathon. Dengue Centinela y Pachamapa son ideas previas del equipo que inspiraron el enfoque; no se reutiliza código de esos proyectos.
